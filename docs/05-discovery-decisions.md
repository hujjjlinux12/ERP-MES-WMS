## 2. 调研顺序

先选择一个典型产品，跟踪一张订单，走完采购、收货、投料、生产、测试、包装和出货。收集脱敏单据、标签及现有台账，再用异常场景补充规则。

| 优先级 | 待确认问题 | 建议参与者 | 影响 |
| --- | --- | --- | --- |
| P0 | 工厂数量、所在地、语言、币种、税务与班次日历 | 负责人、财务 | 组织模型与本地化 |
| P0 | 自有品牌/OEM/ODM？按单生产还是备库？ | 销售、生产 | 订单与工单关系 |
| P0 | 已确认新建 SMT 管理；6 条线是否包含 SMT 线？组装、老化与委外路线是什么？ | 工程、生产 | MES 范围与工艺模型 |
| P0 | 面板、主板、电源板现有条码及追溯要求？ | 品质、工程 | SN 和批次模型 |
| P0 | BOM、替代料、损耗、超领及退料怎样管理？ | 工程、仓库 | 物料消耗规则 |
| P0 | 仓库、线边库、待检区、隔离区如何划分？ | 仓库、品质 | 库存位置和状态 |
| P0 | 哪些单据需要谁审批？金额与数量阈值？ | 负责人、各部门 | 权限与状态机 |

| P1 | 设备测试结果能否导出文件或提供接口？ | 工程、设备供应商 | 集成投入 |
| P1 | 标签格式、客户条码、打印设备和扫码枪型号？ | 仓库、品质、IT | 终端与打印验证 |

| P1 | 数据保存年限、允许停机时长及数据丢失窗口？ | 负责人、品质、IT | 备份恢复和成本 |

## 3. 初始风险

- 2 人同时承担 ERP、MES、WMS 与财务全功能会明显扩大交付风险；一期控制为业务闭环，后续按收益扩展。
- 无既有系统可能意味着物料编码、BOM、库存台账不统一；资料治理应先于大批量开发。
- 条码或设备不具备接口能力时，自动采集会依赖额外硬件与供应商配合。
- 业务负责人投入不足会阻碍验收与切换；需明确每个流程的最终确认人。
