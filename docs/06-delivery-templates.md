# 交付模板

下列模板在实际模块设计时复制填写。未确定内容写“待确认”，不要用推测填充审批、财务或品质规则。

## 1. 详细需求

- 需求编号、名称、版本、负责人、状态。
- 业务目标、参与角色、适用范围、前置条件。
- 主流程、异常流程、结束条件。
- 字段字典：字段、类型、必填、默认值、唯一性、校验、数据来源。
- 状态转换：原状态、动作、目标状态、权限、条件、副作用、撤销方式。
- 页面原型、按钮权限、数据范围、列表筛选、导入导出与打印。
- 业务规则及相关需求编号。
- 验收用例：给定条件、执行动作、预期结果、验收人。
- 影响模块、数据迁移、审计与追溯要求。

## 2. 接口设计

- 接口编号、用途、调用方、负责人、版本。
- 方法、路径、认证、权限、请求与响应结构。
- 参数校验、业务错误码、状态前置条件。
- 幂等键、事务边界、并发冲突处理、超时和重试策略。
- 日志与敏感字段、示例报文、契约测试、兼容与废弃规则。

## 4. 变更申请

变更编号；提出人及日期；原需求；拟变更内容；原因；影响业务、数据、安全、测试、工期及成本；替代方案；批准人；实施版本；验证记录。

## 5. 发布与验收记录

发布版本；需求与缺陷清单；构建标识；测试报告；数据库迁移及演练结果；备份位置与恢复验证；切换步骤；回退触发条件和数据处理方案；负责人；业务验收人；遗留问题及处理期限。
