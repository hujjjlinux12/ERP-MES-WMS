# 产品需求规格说明书（初稿）

状态：待评审。本文定义业务基线；详细字段、页面原型、状态转换表和异常流程在调研后按模块补齐。

范围补充：包含 SMT，板卡生产、料卷及上料防错、板卡到整机追溯见 [SMT 补充需求](07-smt-requirements.md)。已确认 SMT 管理功能由本项目新建；设备接口和具体工艺仍需调研。

## 1. 系统边界

| 领域 | 负责内容 | 边界原则 |
| --- | --- | --- |
| ERP | 采购、销售、BOM、生产工单、业务金额与对账 | 一期不实现完整财务核算及自动 MRP |
| MES | 工单执行、序列号、工序、测试、返修、生产追溯 | 不直接修改库存余额 |
| WMS | 库位、批次、收发存、冻结、盘点、出入库执行 | 所有库存变动通过统一库存服务 |
| 公共平台 | 用户、组织、权限、审计、附件、基础编码 | 权限必须在服务端执行 |

## 2. 主流程

1. 采购人员创建并提交采购订单，审批通过后通知供应商。
2. 仓库按订单收货，创建收货记录及供应商批次，进入待检区域。
3. 品质录入检验结果；合格数量入可用库存，不合格数量隔离并进入退货或处置流程。
4. 生产负责人下达工单，固化产品、BOM 版本、路线与计划数量。
5. 仓库按工单备料和发料；需要线边库时，转移至线边库，再按明确的消耗节点扣减。
6. 产线建立整机 SN，按配置的必经工序执行装配、测试和完工；不良品进入返修与复检。
7. 合格成品通过入库单入库，绑定包装关系。
8. 销售订单产生发货任务，按库位与产品拣货、复核 SN/箱码后出货。

测试项目如点亮、显示性能、老化和安规仅为候选，必须由品质确认实际项目与判定规则。

## 3. 功能与验收基线

| 编号 | 要求 | 主要验收场景 |
| --- | --- | --- |
| FR-001 | 用户、角色、组织、业务操作与数据范围权限 | 无权限用户即使直接调用接口也无法审批或读取受限数据 |
| FR-002 | 物料、单位、产品、供应商、客户、库位基础资料 | 停用物料不能用于新单；历史单仍可查看原始信息 |
| FR-003 | BOM 和工艺路线版本管理 | 已下达工单不因主数据变更而改变其版本快照 |
| FR-004 | 采购订单、审批、分批收货、关闭 | 累计收货超过允许数量时拦截；超收规则需审批确认 |
| FR-005 | 来料检验、合格放行、不合格隔离及采购退货 | 待检或不合格物料不能被正常生产领用 |
| FR-006 | 批次与库位库存、移库、领退料、成品入库 | 重复提交同一业务请求不会产生第二笔库存扣减 |
| FR-007 | 库存冻结、解冻、盘点与差异审批 | 冻结数量不能分配；盘点差异审批后才产生调整流水 |
| FR-008 | 生产工单下达、暂停、完工、关闭 | 暂停工单不能正常报工；短结需记录原因和权限 |
| FR-009 | 工单备料、投料和关键部件绑定 | 批次、料号或替代关系不符合工单配置时阻止投料 |
| FR-010 | SN 发码、扫码、工序顺序校验与防重 | SN 唯一；重复扫码不重复计产；未经授权不能跳站 |
| FR-011 | 测试、不良、返修及复检 | 测试不合格的整机无法进入正常成品放行流程 |
| FR-012 | 整机、箱和托盘包装关系 | 同一 SN 只能属于一个有效包装位置；拆包需保留历史 |
| FR-013 | 销售订单、拣货、复核和出货 | 未放行或已出货 SN 不能重复出货；出货数量与订单校验 |
| FR-014 | 正向与反向追溯 | 从整机查部件批次，从部件批次查关联整机及发货记录 |
| FR-015 | 采购退货、生产退料、报废和单据冲销 | 已过账记录不直接删除，冲销与原记录建立关联 |
| FR-016 | 库存、在制、工单进度与基础良率报表 | 报表可回查单据；良率口径区分首次通过与最终合格 |
| FR-017 | 初始资料和期初库存导入 | 导入先预检；重复导入可识别；期初批次可追溯 |
| FR-018 | 业务金额与对账导出 | 金额按已确认币种、精度与舍入规则计算，可导出复核 |

以上均为一期基线候选，必须在范围评审时逐项确认。销售退货、工单拆分合并、复杂替代料、委外及跨工厂业务暂列待定，不能默认为已覆盖。

## 4. 核心业务规则

- 料号、整机 SN、订单号唯一规则必须明确其组织范围；建议 SN 全局唯一。
- 面板、主板、电源板等关键件追溯到批次还是单件 SN，由实际标签能力及品质要求决定。
- BOM 和工艺路线需有生效时间、版本、审批状态；替代料需授权配置。
- 数量使用明确单位和换算，禁止浮点误差；金额使用十进制定点值。
- 一期默认禁止负库存；例外流程必须单独评审，不能通过手工改余额处理。
- 采用线边库存时，仓库发料是库存位置转移；实际消耗单独入账，禁止发料和投料重复扣减。
- 库存现存量、冻结量、预留量及可用量定义必须一致，冻结与预留不可重复计算。
- 记录业务发生时间与系统接收时间；跨班次和跨日归属按工厂确认的日历执行。
- 任何业务绕过、补录或冲销都需要原因、操作者和关联记录。

## 5. 非功能需求

| 编号 | 要求 | 验证方式 |
| --- | --- | --- |
| NFR-001 | 多人并发领料和出货不造成超扣或重复执行 | 并发及重复请求集成测试 |
| NFR-002 | 操作审计包含用户、时间、对象、动作与结果 | 抽查关键业务记录及受限访问 |
| NFR-003 | 备份可恢复，明确恢复时间 RTO 与数据丢失窗口 RPO | 隔离环境恢复演练；数值待业务确认 |
| NFR-004 | 扫码操作及时反馈 | 按实际终端和并发负载确定 P95 响应目标后压测 |
| NFR-005 | 内网故障时现场应急流程 | 演练停机、纸质记录、恢复及补录对账 |
| NFR-006 | 追溯记录保存期、导出权限和附件容量受控 | 按客户与工厂要求确认后验证 |

一期建议在线操作，离线自动同步另立需求。界面语言、打印格式、时区、币种和税务地区均待确认。
