# SMT 业务与追溯补充需求

状态：0.1 草案，2026-11-06。已确认包含 SMT；本文件描述拟议业务能力，不代表工厂已采用其中每种设备或工艺。已确认 SMT 管理功能由本项目新建，设备接口能力和具体工艺待调研。

## 1. 业务边界与实施方式

ERP 管理多层 BOM、板卡生产工单及整机生产工单；WMS 管理电子料、料卷、PCB、板卡和相关库存；MES 管理 SMT 执行、上料校验、板卡品质及整机装配绑定。

本项目新建 SMT 管理能力，先实现扫码驱动的基础管理，再按设备条件逐步增加采集。ERP、WMS 和 MES 共用已定义的主数据与库存规则，避免重复扣料或发码。软件校验不等于设备自动停机，设备联锁需要独立设计与现场验证。

## 2. 候选业务流程

电子料收货与检验 → 料卷建档 → 按板卡工单备料 → 上料与换料校验 → 板卡生产和检测 → 不良隔离、返修与复检 → 合格板卡入库或受控转序 → 整机领用及板卡 SN 绑定。

印刷、SPI、贴片、回流、AOI、ICT/FCT 等作为待确认的工序候选；依据实际设备与品质要求配置必经站点。双面生产、拼板及分板需要明确追溯方式。

## 3. 功能与验收标准

| 编号 | 拟议要求 | 验收基线 |
| --- | --- | --- |
| SMT-001 | 多层 BOM 与板卡工单 | 板卡工单引用已批准版本；整机 BOM 可引用板卡半成品 |
| SMT-002 | 料卷唯一标识 | 同一来料批次可含多个料卷；每卷独立记录料号、批次、数量与状态 |
| SMT-003 | 分卷、合卷、退料与数量调整 | 保留来源关系及数量流水；不得通过覆盖余量丢失历史 |
| SMT-004 | 站位表、程序与 BOM 版本关联 | 工单换型时校验适用版本；错误版本不能正常放行 |
| SMT-005 | 上料、换料、接料校验 | 错料、禁用料、未批准替代料或无效批次被拦截并记录 |
| SMT-006 | 工单发料、耗料、损耗与退料对账 | 位置转移不重复计入消耗；账实差异进入审批处理 |
| SMT-007 | 板卡身份与拼板关系 | 可从单板追溯原拼板及有效生产记录；分板不丢失来源 |
| SMT-008 | 检测、不良、返修与复检 | 保留历次结果，未放行板卡不能正常进入整机装配 |
| SMT-009 | 板卡到整机绑定与拆换 | 整机可追溯板卡，拆换记录旧件、新件、原因与操作者 |
| SMT-010 | 物料批次影响范围查询 | 可查生产期间使用该批次的板卡及关联整机；明确数据精度 |
| SMT-011 | 设备数据接入（条件范围） | 重传不重复记账；无法识别 SN 的数据进入异常处理 |
| SMT-012 | 特殊物料时效管理（适用时） | 按品质批准规则管理开封、暴露、回温、使用期限及处置 |

## 4. 追溯精度与消耗原则

追溯目标链：供应商批次 → 料卷 → 上料/换料记录 → 板卡生产记录 → 板卡 SN → 整机 SN → 包装 → 出货。

精确到单板的电子元件批次关系，依赖设备数据或可靠的过站、换料时间与数量边界。仅有工单发料记录时，只能提供工单级候选影响范围，不能宣称实现精确单板追溯。需要在验收中标注“精确绑定”与“范围推定”的区别。

消耗来源可选设备实耗、人工确认或按 BOM 理论倒冲，必须明确选用方式和适用物料。理论消耗应与实际余料、抛料和报废定期对账，同一消耗不得被设备接口和人工报工重复入账。

板卡转入整机生产的物流方式需明确：入半成品库后领用，或受控在制转序。一个流转过程只能有一套有效库存记账依据。

## 5. 数据设计补充

候选实体：Reel（料卷）、ReelGenealogy（分合卷关系）、FeederSetupVersion（站位版本）、MaterialLoadingRecord（上换料记录）、PanelSerial（拼板）、BoardSerial（单板）、PanelBoardRelation、MaterialConsumption、EquipmentResult、BoardUnitBinding。

料卷余量与库存数量之间必须明确单位和责任边界；分合卷及调整在事务内维护数量守恒。板卡绑定关系保留有效起止时间和历史，禁止仅覆盖当前主板 SN。设备原始记录与业务判定分开保存并相互关联。

## 6. 优先调研事项

- 6 条线是否包含 SMT？SMT 线数量、设备品牌型号、单/双面、拼板形式和板卡产量分别是什么？
- 设备供应商是否提供采集接口文档、数据导出权限及调试支持？
- 板卡何时赋码、何时分板？目前能否稳定读取单板或拼板标识？
- 上料校验使用哪些终端，是否要求机台联锁？
- 电子料是否已有内部料卷码？实际余料及抛料如何统计？
- 哪些物料需要湿敏、锡膏或其他时效管控？具体规则由谁批准？
- 板卡与整机如何交接，返修更换的板卡如何入账与追溯？

## 7. 试点与计划影响

建议选择一款产品的一种板卡和一条 SMT 线，验证“料卷 → 上料 → 板卡 → 整机”的完整链路，再推广。本项目先实现人工扫码基础闭环，并验证耗料与库存对账。设备采集与联锁另行估算，不沿用原排期承诺。
